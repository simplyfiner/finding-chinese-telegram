# Telegram 的中文内容，都藏在哪
---

先问个问题。

Telegram 上一共有多少中文频道？

没人答得上来。

不是没人统计过，是这件事压根没法统计。

因为**没有地方在记录它们**。

---

上周我想找个聊前端的中文频道，找了一晚上，顺手把自己试过的路子记了下来。

后来发现，这些路子合起来，恰好能回答开头那个问题。

### 一、不在官方搜索里

打开 Telegram，搜「前端」。

出来一堆不认识的账号，几个无关的群，还有一个卖东西的。

换「前端开发」，一样。

换「前端 中文」，还是一样。

Telegram 的搜索不差 —— 搜联系人、翻聊天记录、找表情包，都挺利索。

唯独搜公开频道，尤其中文的，基本是坏的。

原因不难猜：**中文没有空格。**

英文天然分词，`web dev` 就是两个词。中文不一样，「前端开发」在它眼里可能是一个整体，也可能被切成别的组合。

你搜「前端」，它未必能匹配到名字里就带「前端」的频道。

而且官方搜索的优先级是：你的联系人 > 你加入的群 > 你的聊天记录 > 最后才是公开频道。

它是**找已知**的工具，不是**发现未知**的工具。

而"找频道"这件事的本质，恰恰是我不知道它存不存在。

这条路官方压根没给。

### 二、不在 Google 的排序里

`site:t.me 前端 频道`，能搜出一些。

但排在前面的未必是好频道，往往是 SEO 做得好的。

内容质量不参与排序，链接的"存在感"才参与。

而且不少点进去已经失效，或者频道早改行做别的了。

你能搜到它，不代表它还在那儿。

### 三、在你收藏夹那篇两年前的文章里

我记得存过一篇「100 个必关注的 Telegram 频道」。

翻出来一看，发在两年前。

挨个点过去，三分之一打不开，还有几个点进去发现内容早就变味了。

这类导航文章的问题不是写得不好，是**它是一张快照**。

频道会关、会改名、会转型，但文章不会更新。

半年过去，一半失效。

### 四、在别人的聊天记录里

最后我在几个技术群里问了一圈。

有人丢了个链接，说「这个还行」。

点进去是个两千人的大群 —— 不是我想找的那种内容频道。

但这也是目前**最有效**的方式。

官方没有目录，没有标签，没有类目树。

频道叫什么、属于哪个领域，全凭创建者心情。

于是发现渠道退化成了最原始的形式：**人传人**。

有人在群里丢个链接，你点进去，哦，还有这么个频道。

效率取决于你的人脉，不取决于内容质量。

### 五、在英文数据站的付费墙后面

TGStat 那种第三方数据站，数据是全的。

但界面基本是英文，中文频道收录稀疏，核心功能在付费墙后面。

它能告诉你一个频道的订阅数曲线，但没法告诉你"中文圈里有哪些值得一读的技术频道"。

覆盖面和语言，两头都不靠。

---

### 所以它们藏在哪

答案有点讽刺：**哪儿都在，哪儿都不在。**

内容是真的有的 —— 中文 Telegram 圈的活跃度一点不低，技术、资讯、影音、资源，什么都有。

但它们是**散落**的。

散在搜索的盲区里，散在失效的收藏里，散在别人的聊天记录里，散在付费墙后面。

不是没有，是没有一个地方把它们放在一起。

你要的东西其实很朴素：

一个能按类目浏览、能直接搜关键词、收录以中文为主的索引。

后来我找到了：[电报导航](https://tgindex.org)。

### 它在做的事

**先把三类实体分开。**

频道、群组、机器人各有独立入口：

- 频道 — https://tgindex.org/channel/
- 群组 — https://tgindex.org/group/
- 机器人 — https://tgindex.org/robot/

很多目录站是把三者混在一起的，你搜个关键词出来一堆机器人，找频道还得自己筛一遍。

**再建分类。**

20 多个类目：资讯新闻、影音资源、资源分享、软件综合、知识学习、iOS 资源、兴趣社群……

你可以不搜索，直接按类目往下翻。

对"我也不知道要找什么，就是想看看有什么"这种场景，比搜索有用得多。

**搜索免登录。**

```
https://tgindex.org/search?q=关键词
```

打开就能搜，不用注册，没有付费墙。

**收录是开放的。**

发现好频道可以自己提交（https://tgindex.org/submit），觉得某条收录有问题也能举报。

散落的东西之所以散落，就是因为没人持续捡。开放提交至少让这件事能转起来。

**还有个细节：它自己能被索引。**

页面带 Schema.org 结构化数据，`sitemap.xml` 也是通的。

一个做索引的站，自己都不被索引就搞笑了 —— 这点它没翻车。

### 也说说局限

- **规模还不算大。** 各分类加起来一千多条，跟百万级的数据站没法比。它聚焦中文，取舍就在这。
- **质量依赖社区。** 开放提交意味着良莠不齐，能举报，但处理速度取决于维护者。
- **首页推荐位的筛选还不够严。** 我翻的时候看到过几条明显不该出现的收录混在里面，加一层过滤会好很多。

### 最后

回到开头那个问题：Telegram 的中文内容，都藏在哪。

现在至少有了一个地方，是专门把它们摆在一起的。

不用注册，打开就能搜：

https://tgindex.org

要是你在上面发现了什么好频道，记得顺手提交一下。

散落的东西，得靠一个个捡回来。
